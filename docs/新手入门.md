# 新手入门（量化小白）

目标：用 **模拟盘（SIM）** 在 10 分钟内跑通「策略自动下单」，再考虑真钱。

## 你只需要记住

| 词 | 意思 |
|----|------|
| SIM | 模拟盘，假钱，用来练 |
| LIVE | 实盘，真钱，先别开 |
| 策略 | 一套自动买卖规则 |
| Tick | 立刻让策略算一轮并可能下单 |

## 最短 5 步

1. 打开控制台 → 左侧点 **新手入门**（或本页）  
2. **总览** →「启动 SIM」  
3. **策略** → 打开「双均线示例」  
4. **总览** →「执行一次 Tick」→ **订单** 看成交  
5. （可选）**回测** 试参数；真钱前读 `docs/部署与使用说明.md`

## 菜单要不要用？

| 页面 | 要不要 | 干什么 |
|------|--------|--------|
| 新手入门 | 建议先看 | 带你走通一遍 |
| 总览 | **必做** | 开关 SIM/LIVE、看钱、对账 |
| 策略 | **必做** | 决定自动买卖谁、参数多少 |
| 订单 | **必做** | 持仓、成交、手工试单 |
| 情报交易 | 常用 | 新闻+大模型预测后分散自动买卖（先 SIM） |
| 回测 | 常用 | 历史数据验策略，不下真单 |
| 风控 | 进阶 | 看为什么被系统拦下 |
| 告警 | 进阶 | 异常通知 |

日常极简路径：**总览 → 策略 → 订单**。情报路径见 [情报交易.md](./情报交易.md)。

## 什么时候才碰真钱？

SIM 已经能稳定看到订单、你能看懂拒单原因之后，再：

1. Windows 装券商 QMT + 启动 XQA  
2. 控制面改 `remote_xtquant`  
3. 白名单 + 手工 100 股验证  
4. 再开 LIVE  

详见 [部署与使用说明.md](./部署与使用说明.md)。
