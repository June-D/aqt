# 情报交易（新闻 → LLM → 分散下单）

## 做什么

热点股票池 → **千帆 AppBuilder AI 搜索** 按代码搜实时资讯 → OpenAI 兼容大模型预测涨跌 → 按分散规则自动买卖。

## 使用前检查

1. `.env` 填写 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`  
2. `.env` 填写 **`APPBUILDER_TOKEN`**（千帆 / AppBuilder 控制台的 API Key，国内可达）  
3. 交易池：东财热点榜自动刷新（`intel.hot_pool`）；也可手工 `risk.whitelist`  
4. 新闻默认 **`news_provider: appbuilder`**；可改 `rss` / `hybrid`（搜索 + RSS）/ `tavily`（外网）  
5. SIM 试跑 → 情报页「刷新热点池」→「立即跑一轮」；LIVE 需 XQA  

`intel.appbuilder.symbols_per_run` 控制每轮搜几只票（默认 12）。

密钥位置：百度智能云千帆 / AppBuilder 控制台 → API Key。请求走 `https://qianfan.baidubce.com/v2/ai_search/web_search`。

## 闸门（Q5）

- LIVE 开关（远程网关）  
- 交易池非空  
- 同标的冷却、置信度、单票/现金/持仓/行业上限  

## 付费新闻源

在 `intel.http_sources` 按通用 JSON 适配器配置即可（见 `default.yaml` 注释）。
