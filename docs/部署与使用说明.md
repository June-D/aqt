# AQT 部署说明与平台使用说明

面向准备 **真实交易（LIVE）** 的运维与日常操作。默认仍是 SIM；LIVE 会动用真实资金，后果自负。

**小白上手：** 打开控制台左侧「新手入门」，或读 [新手入门.md](./新手入门.md)。

---

## 一、架构一览

```text
浏览器 UI ──► Mac/Linux 控制面 (FastAPI :8000)
                    │
                    ├─ SIM 网关（本地模拟，默认）
                    └─ RemoteXtQuant ──HTTP──► Windows XQA (:8100)
                                                    │
                                                    └─ 券商终端 + xtquant
```

| 组件 | 跑在哪 | 作用 |
|------|--------|------|
| 控制面 + UI | Mac / Linux（推荐本机或内网机） | 策略、回测、风控、调度、开关 LIVE |
| XQA Agent | Windows（已登录 miniQMT / 券商终端） | 真下单、查持仓、查资金 |
| SQLite | 控制面机器 `data/trade.db` | 订单、策略、回测、告警 |

**两道闸门（必须都开才会实盘下单）：**

1. `.env` 里 `GATEWAY_TYPE=remote_xtquant` 且 XQA 健康  
2. UI「总览」打开 **LIVE**（或 `.env` 里 `LIVE_TRADING_ENABLED=true` 后重启，仍建议以 UI 为准）

只配了远程网关、没开 LIVE → 订单会被拒绝，不会实盘成交。

## 二、部署说明

### 2.1 控制面（Mac / Linux）

#### 环境要求

- Python 3.10+
- Node.js 18+（构建前端）
- 能访问行情源（akshare / 外网）；与 Windows 机器 **内网互通**（控制面 → `WindowsIP:8100`）

#### 安装与启动

```bash
cd /path/to/trade
cp .env.example .env
# 编辑 .env（见下文「实盘关键配置」）

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cd frontend && npm install --registry=https://registry.npmjs.org/ && npm run build && cd ..

mkdir -p data/cache
export PYTHONPATH="$(pwd)"
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

或一键：

```bash
./scripts/run_dev.sh
```

- 控制台：http://控制面IP:8000  
- 冒烟（SIM）：`./scripts/smoke.sh`（服务已启动时）

#### 建议用 systemd / launchd 常驻（示例 systemd）

```ini
[Unit]
Description=AQT Control Plane
After=network.target

[Service]
WorkingDirectory=/path/to/trade
Environment=PYTHONPATH=/path/to/trade
EnvironmentFile=/path/to/trade/.env
ExecStart=/path/to/trade/.venv/bin/python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

#### 实盘关键配置（`.env`）

```env
APP_HOST=0.0.0.0
APP_PORT=8000
DATABASE_URL=sqlite:///./data/trade.db

# 实盘：改成 remote_xtquant
GATEWAY_TYPE=remote_xtquant
GATEWAY_URL=http://<Windows局域网IP>:8100
GATEWAY_TOKEN=<两端一致的长随机串>

# 启动时默认关 LIVE；开盘前在 UI 再开
LIVE_TRADING_ENABLED=false

# 强烈建议设置，否则任何人可访问控制台
APP_PASSWORD=<你的访问密码>

INITIAL_CASH=1000000
```

`GATEWAY_TOKEN` 请用随机串，控制面与 Windows Agent **必须相同**。

#### 实盘前必须改的 YAML（`configs/default.yaml`）

```yaml
paper:
  poll_interval_seconds: 60
  force_run_outside_session: false   # 实盘务必 false，禁止盘外自动下单

risk:
  max_position_pct: 0.20             # 按你的承受力收紧
  max_total_position_pct: 0.80
  max_daily_loss_pct: 0.03
  max_strategy_position_pct: 0.40
  min_trade_interval_seconds: 60
  lot_size: 100
  whitelist: ["600519"]              # 建议先白名单 1～几只票
  blacklist: []

alerts:
  webhook_url: ""                    # 可选：企业微信/钉钉机器人 URL
```

交易日历：`configs/calendar.yaml`（节假日 / 补班）。每年初核对一次。

#### 情报交易（可选）

新闻 → LLM → 分散下单。配置 `LLM_*`（或界面填写）、保持 `risk.whitelist` 非空，SIM 验证后再 LIVE。详见 [情报交易.md](./情报交易.md)。

#### 防火墙

- 控制面 `8000`：仅本机或可信内网  
- Windows `8100`：仅允许控制面 IP 访问，**不要对公网开放**

### 2.2 Windows XQA（真下单端）

#### 环境要求

- 已安装并 **登录** 支持 xtquant 的券商终端（如 miniQMT）
- Windows 上 Python 3.10+（与终端/xtquant 版本匹配）
- 本仓库代码同步到 Windows（整仓拷贝或 git clone）

#### 配置环境变量（PowerShell 示例）

```powershell
$env:GATEWAY_TOKEN = "<与控制面相同>"
$env:QMT_ACCOUNT_ID = "<资金账号>"
$env:QMT_USERDATA_PATH = "C:\path\to\userdata"   # 终端 userdata 目录
$env:AGENT_HOST = "0.0.0.0"
$env:AGENT_PORT = "8100"
```

`QMT_USERDATA_PATH` 以你券商文档为准，常见为客户端安装目录下的 `userdata`。

#### 安装依赖并启动

在仓库根目录：

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
# xtquant 一般由券商终端自带 Python 路径提供；若 import 失败，用终端自带解释器运行 Agent

$env:PYTHONPATH = (Get-Location).Path
python -m agent.main
```

健康检查（在控制面或 Windows 本机）：

```bash
curl -H "Authorization: Bearer <GATEWAY_TOKEN>" http://<WindowsIP>:8100/health
```

期望字段：

| 字段 | 含义 |
|------|------|
| `ok: true` | Agent 进程正常 |
| `xtquant_imported: true` | 能 import xtquant |
| `account_id_configured` / `userdata_configured` | 环境变量已配 |
| `wired: true` | 具备对接条件（仍须终端已登录） |
| `connected` | 已成功连上交易接口（首次下单/查询时会 connect） |

若 `xtquant_imported: false` 或 `wired: false`：**不要开 LIVE**。Agent 会拒绝下单，不会假装成交。

更短的清单见 [agent/README.md](../agent/README.md)。

1. [ ] SIM 冒烟通过：`./scripts/smoke.sh`  
2. [ ] `force_run_outside_session: false`

## 三、平台使用说明

打开 http://控制面:8000 。若配置了 `APP_PASSWORD`，先登录。

顶部状态芯片：

- **网关**：`sim` 或 `remote_xtquant`；异常时不要开 LIVE  
- **SIM 开/关**：本地模拟调度是否在跑  
- **LIVE 开/关**：是否允许实盘下单  

### 3.1 总览

| 操作 | 说明 |
|------|------|
| 启动 / 停止 SIM | 启停纸面调度（按 `poll_interval_seconds` 拉日线跑策略） |
| 执行一次 Tick | 立刻跑一轮策略信号（调试用） |
| 对账 | 拉取网关账户/持仓快照，异常写入告警 |
| LIVE 开关 | 打开后，远程网关才允许下单；关闭立即挡单 |

账户卡片：总资产 / 现金 / 市值 / 当日盈亏（SIM 为本地账本；LIVE 为 XQA 查询结果）。

### 3.2 策略

- **新建 / 编辑**：ID、名称、类型（`MaCrossStrategy` / `BreakoutStrategy`）、标的、参数 JSON  
- **启用**：打开开关后，SIM 调度才会交易该策略  
- **删除**：去掉配置（历史订单仍保留）  

参数示例：

```json
{"fast": 5, "slow": 20, "trade_pct": 0.05}
```

`trade_pct`：买入时用可用资金的比例；卖出为全平该标的持仓（按当前实现）。实盘建议先 `0.05`～`0.1`。

内置类型：

- **双均线** `MaCrossStrategy`：快线上穿/下穿慢线  
- **N 日突破** `BreakoutStrategy`：突破近 N 日高低点  

信号基于 **日线**；调度间隔默认 60 秒，同一根 K 线可能重复评估，依赖风控「最小交易间隔」限频。

### 3.3 回测

1. 选策略、标的、起止日期 → **运行**  
2. 点历史行看净值与指标  
3. **参数扫描**：网格 JSON 如 `{"fast":[5,8],"slow":[20]}`，最多约 12 组  

回测只读行情与本地引擎，**不会下单**。

### 3.4 订单

- **持仓 / 订单流水**：来自当前网关（SIM 或 XQA）  
- **手工下单**：仍走风控；实盘最小验证用此入口  
- **撤单**：状态为已提交 / 部分成交时可用（SIM 与远端能力以网关为准）  

### 3.5 风控

查看被拦截订单及原因，例如：LIVE 关闭、非交易日、非整手、资金不足、单票/总仓/策略仓超限、白名单、涨跌停粗检等。

### 3.6 告警

风控熔断、网关对账失败等。可点「已读」。配置 `alerts.webhook_url` 可推到外部机器人。

## 四、推荐日常流程

### 仅研究 / 模拟（默认）

1. `GATEWAY_TYPE=sim`  
2. 总览启动 SIM，或按需 Tick  
3. 策略页启停；回测页验证参数  
4. **不要开 LIVE**

### 切到真实交易

1. Windows：终端登录 → 启动 `python -m agent.main`  
2. 控制面：`.env` 改为 `remote_xtquant`，重启 uvicorn  
3. UI 确认网关正常；风控白名单收紧；策略先全关  
4. **手工买 100 股试验标的** → 在券商端核对  
5. 确认无误后：开 LIVE → 启用 1 个策略、小仓位  
6. 收盘：关 LIVE → 停策略 →（可选）停 Windows Agent  

### 紧急停机

1. UI 关闭 **LIVE**  
2. 停止所有策略开关  
3. 停止 SIM  
4. 在券商终端手动撤单 / 平仓（以终端为准）  
5. 停 Windows Agent 进程

## 五、常见问题

| 现象 | 处理 |
|------|------|
| 下单提示 LIVE 未开启 | 总览打开 LIVE；确认网关是 `remote_xtquant` |
| 网关异常 / unreachable | 查 Windows 防火墙、IP、TOKEN、Agent 是否在跑 |
| health 里 xtquant 为 false | 用券商自带 Python，或把 xtquant 加入 `PYTHONPATH` |
| 盘外还在下单 | 设 `force_run_outside_session: false` 并重启 |
| 总被风控拒 | 看「风控」页原因；检查白名单、仓位上限、整手 100 |
| 登录页进不去 | `.env` 的 `APP_PASSWORD`；改完需重启服务 |
| 策略改了 YAML 没生效 | 已存在的策略以 UI/数据库为准，YAML 只种子「尚不存在」的 ID |
